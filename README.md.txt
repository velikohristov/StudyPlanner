# StudyPlanner

StudyPlanner is an ASP.NET Core MVC application for managing courses and study notes.

## Features
- Manage courses
- Add, edit, and delete study notes
- Use SQL Server and Entity Framework Core
- CRUD operations
- Responsive UI with Bootstrap

## Technologies
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap

## Setup
1. Install .NET 8 SDK
2. Open the project in Visual Studio
3. Restore NuGet packages
4. Update the connection string in `appsettings.json`
5. Run:
   ```bash
   dotnet ef database update
